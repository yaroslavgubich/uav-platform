# UAV Platform

A personal project focused on the development of a 7-inch UAV platform based on ArduPilot.

## Project Goals

* Autonomous waypoint navigation
* Return-to-Launch (RTL)
* GPS-assisted flight
* Camera payload integration
* Custom CAD-designed components
* Rapid prototyping and iterative development
* System integration and flight testing

## Technologies

### Flight Control

* ArduPilot
* Mission Planner

### Design & Manufacturing

* SolidWorks
* Blender
* Bambu Studio
* OrcaSlicer

### Hardware

* Flight Controller
* GPS Module
* Telemetry System
* FPV System
* Brushless Motors
* Electronic Speed Controllers (ESC)

## Repository Structure

```text
docs/           Project documentation
cad/            CAD models and technical drawings
electronics/    Wiring diagrams and hardware documentation
photos/         Build progress photos
flight-tests/   Flight logs and test reports
mission-plans/  Autonomous mission configurations
media/          Videos and screenshots
```
